# 图书来源索引

用于后续记录图书线上地址及其对应的本地版本。AI 读取本地文件；Git 仅管理这份来源索引，不存储或上传图书源文件。

目前尚未提供图书线上地址，暂未登记图书。

## 维护约定

- 收到具体地址后再登记，先核对链接对应的图书、版本和本地文件；同名书的不同版本分开记录。
- 优先记录公开、稳定的来源落地页或永久链接，不保存令牌、签名和私密参数。临时授权下载地址仅在实际使用时另行提供。
- 本地文件只记相对文件名，不记个人电脑的绝对路径。源文件放在 `books/`；扫描图片、压缩包和其他格式的原书也遵循此约定。
- 不把原书全文、OCR、提取全文或源文件附件放入本索引或其他受 Git 管理的目录；提取结果保留在本机 `output/`。
- SHA-256 可从本地文件计算，或使用解析结果 `book.json` 中的 `source.sha256`，用于确认具体版本，不需要上传原书。
